# Two Pointers Pattern

This folder contains problems solved using the Two Pointers technique.

## Core Idea

Use two indices to traverse the array in a smart way instead of brute force.
Usually the array is sorted, and we move pointers based on a condition.

#types of 2pointers
1. opposite ends: one at start and the other at ending
2. same direction: (fast & slow) these are bestly used in linked lists and I too have that repo, check it.

## Typical Use Cases

- Finding pairs or triplets with a target sum
- Shrinking search space from both ends
- Removing duplicates efficiently
- Partitioning arrays (Dutch National Flag)
